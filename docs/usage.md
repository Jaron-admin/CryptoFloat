# DuoMonitor 使用文档

**简体中文** · [English](usage.en.md) · [项目首页](../README.md)

行情、自定义 JSON API 字段、文字和本机系统数据可以显示在桌面悬浮窗及 Windows 主屏任务栏内部。两处独立选择内容和外观，数据源与系统设备设置共享。目前仅支持 Windows 10/11 x64；macOS/Linux 工程骨架尚未完成原生窗口、密钥保护、系统采集和任务栏适配。

## 使用

发布目录中的 `duomonitor.exe` 可以直接启动；整个目录需要一起保留，包括 `duomonitor_taskbar.exe`、运行库和 `data`，不能单独复制主 EXE。任务栏宿主由主程序管理，只接收显示文本与外观，不接收 API 地址或密钥。程序使用 Windows 图形应用入口，正常启动不创建命令行窗口。

解压到具有写入权限的目录。程序默认使用 EXE 同级的 `user_data` 保存个人数据，目录不可写时会提示。设置中的“导入与数据位置”可以改到 `%APPDATA%\DuoMonitor`，并在切换时选择复制现有数据。同一 Windows 用户的当前登录会话只允许一个实例，即使从另一个便携版目录启动，也会唤回已运行的窗口；隐藏在托盘中的窗口会重新显示。升级前请退出旧版并备份完整的当前数据目录；便携模式把 `user_data` 保留在新程序旁。

- 标题区域拖动窗口，拖动窗口边缘调整大小；右键悬浮窗任意位置打开 Windows 标准菜单。双击悬浮窗隐藏到右下角托盘，单击托盘图标恢复；托盘右键也可刷新、进入设置或退出。图标可能被 Windows 收进 `^` 隐藏区域。设置页标题也可拖动窗口。
- 设置使用 Flutter Material 3 控件。左侧分类与搜索，右侧分组设置；较窄窗口会调整为图标侧栏或横向分类导航。点击 **保存** 提交更改后留在当前页；点击设置外或返回悬浮窗仍会自动保存，失败时保留草稿。保存期间的关闭请求会等待当前提交完成。Alt+Tab、取色器、字体选择器和文件选择框不会误触发关闭。
- 只有设置页显示应用任务栏按钮；关闭设置窗口（包括 Alt+F4 或任务栏关闭命令）会保存后返回悬浮窗。关闭悬浮窗会隐藏到托盘，明确选择 **退出** 才结束程序。
- **关注行情**：自动载入 OKX、Binance、KuCoin 的完整可用现货交易对目录，按名称、代码和交易所搜索勾选；目录只显示名称和代码，不请求所有价格。采集两个已启用显示的依赖并集，同一行情不会因两处同时显示而重复请求。目录每 24 小时更新并缓存，也可手动刷新；单家失败保留其上次目录。股票/ETF 仍有常用列表，也可手动添加代码。“已关注”位于页面上方，支持拖动左侧手柄排序，也可点击每项右侧的上移、下移按钮；较长列表可滚动。关闭设置并成功保存后，当前显示目标使用同样的顺序。
- **自定义内容**：填写 HTTPS GET JSON 地址，读取返回字段，选取要显示的内容并设置名称、单位。请求头密钥由 Windows 当前用户的 DPAPI 保护，配置文件只记录引用。
- **显示布局**：默认行情与自由显示行可以同时显示；也能关闭默认行情列。使用文字和字段组合显示行，调整顺序和小数格式；编辑器与悬浮窗使用相同的渲染。
- **实用模板**：添加城市天气、参考汇率、GitHub 公开仓库统计、简洁行情条或文字提醒。模板追加到当前草稿，保留现有内容；字段与文字可继续编辑。
- **外观**：“悬浮窗透明度”位于页面最上方，0% 表示完全不透明。分别选择系统文字/数字字体，调整字号与间距；字体选择器预览含中英文及数字。
- **语言**：在“外观 → 语言”中选择简体中文、English 或跟随系统。选择后可在设置中即时预览，点击保存或关闭设置时保留选择；界面、提示、悬浮窗和托盘菜单使用所选语言，再次启动时保留选择。自定义名称、显示文本及接口返回内容保留原值。
- **浅色与深色**：主题模式可选浅色、深色、跟随系统；两套配色独立保存。提供 Fluent 蓝、Catppuccin、Nord、Solarized 四组浅深预设，并保留独立自定义背景。“将当前配色另存为主题”可创建任意多套命名预设；每套包含浅、深两组颜色，支持编辑、复制、删除。图形取色器提供方形色谱、色相/亮度滑条、RGB/HEX 输入与实时预览，可分别设置背景、卡片、文字、次级文字、边框、强调色、上涨和下跌颜色。图标下拉显示真实图形，旁边可预览表情和本地图片。
- **单位与换算**：管理单位简写、自定义标签、显示货币和固定倍率。
- **窗口与托盘**：调整置顶，查看窗口移动与托盘操作；透明度在“外观”中调整。
- **名称与图标**：修改悬浮窗左上角名称，选择内置图标、表情或本地图片，也能分别隐藏名称和图标。本地图片上限 1 MB，导入后保存为应用私有 PNG，不改原图片。

手动保存后页面显示已保存；关闭设置时自动保存成功会短暂提示。菜单打开后，点击菜单以外的位置可以关闭。

交易对目录中勾选或取消项目时保持当前列表位置；重新进入关注行情页面或手动刷新目录时，再将已勾选项目排到前面。

悬浮窗和托盘右键菜单使用 Windows 标准原生菜单，可超出小悬浮窗边界；字体、颜色、间距和勾选标记由系统绘制，支持方向键、Enter 和 Esc。设置页使用 Flutter Material 3；桌面窗口、托盘和跨窗口右键菜单由平台适配层处理。

配色参考 [Microsoft Fluent](https://fluent2.microsoft.design/color)、[Catppuccin Latte/Mocha](https://catppuccin.com/palette/)、[Nord](https://www.nordtheme.com/docs/colors-and-palettes/) 与 [Solarized](https://ethanschoonover.com/solarized/)。部分强调色与涨跌颜色为行情小字的对比度作了调整。

## 两处独立显示

默认同时启用行情悬浮窗和任务栏系统监测。任务栏默认选择 CPU、内存百分比、上传和下载速率。设置中先选择 **悬浮窗** 或 **任务栏**，再编辑关注行情、自定义字段、显示模板、系统指标、排序、文字/数字字体、主题和单位。两处可以显示完全不同的内容；仅调整排序不会重新请求全部行情。

“显示布局”可选择悬浮窗 1–8 列，每项可横向或纵向排列；多列超出当前宽度时可横向滚动。名称靠左、数字和价格靠右对齐。数字字体控件提示等宽字体更适合数字，并标出已安装的常见等宽字体。

“价格颜色”同时作用于悬浮窗与任务栏，可选默认主题文字、主题涨跌色、绿涨红跌或红涨绿跌。方向比较相邻两次成功刷新的价格；首次成功刷新、价格相同或本次刷新失败时为中性色。刷新失败保留上次成功价格作为下次比较基准。24h 涨跌幅有自己的数值和颜色，可独立隐藏，不决定价格颜色。设置分区会标明共享、仅悬浮窗或仅任务栏的影响范围。

“任务栏布局”单独控制启停、单行/双行、透明背景、名称与数值间距、项目间距和轮播。窗口按实际文字与检测到的空白区域自动伸缩，没有人为最大宽度。放不下时按完整列分页，支持滚轮或自动轮播；默认 5 秒，可调 2–60 秒，悬停或手动滚动时暂停。双行同列保持一起；单个项目长于可用区域时才省略文字，悬停可查看详情。

系统任务栏居中对齐时优先使用最左侧足够的空白，否则使用已确认的较宽空白，避开天气、小组件和其他控件。无法可靠确认空白区域时暂停显示。

“名称显示”可选自动简写或完整名称；加密货币自动简写会去掉可识别的交易对计价币后缀，例如 BTC-USDT → BTC。“自定义简写”可为行情、系统指标、API 字段和显示行逐项设置任务栏名称，留空恢复自动名称。简写不修改原始名称、字段标识或数据，悬停提示保留原始名称与数值。

设置中的固定预览区显示当前目标的草稿与已有行情。字体、配色、间距、布局和精度调整立即可见，点击保存或关闭设置后应用；保存失败保留草稿。显示布局中的“价格显示精度”可按币种选择普通数字或 K/M/B 缩写，以及自动或 0–8 位小数，例如 `81,678.42` 显示为 `81.7K`。K 为千、M 为百万、B 为十亿；两处独立保存，原始价格与涨跌判断不受影响。新加入但尚未取得行情的项目显示 `—`。删除共享数据源或字段前，需要先移除两处引用，包括已关闭的显示配置。

任务栏首期针对主屏的 Windows 标准任务栏，使用独立原生文本宿主；其他显示器和第三方任务栏不在当前支持范围。Windows 11 没有受支持的第三方预留布局位置，只有确认有空余区域才尝试显示，不移动系统控件腾位置。空间不足或布局无法确认时暂停，保留设置。设置显示宿主报告的“已关闭”“正在显示”“等待任务栏就绪”“空间不足”“暂不支持”或“暂不可用”等状态，不能仅凭“正在显示”判断实际画面已验证。不同系统版本和桌面布局仍需分别验证兼容性。

任务栏右键可打开设置、刷新、显示悬浮窗、关闭任务栏或退出。任务栏宿主随主程序退出，连接断开时撤除显示。任务栏重启、主题、DPI 或自动隐藏状态改变时重新检测。真实 Windows 桌面布局的兼容性仍需单独验证；本地隔离测试不代表已验证每种任务栏。

## 本机系统监测

在 **系统监测** 中选择当前显示所需指标并排序。CPU、内存、GPU 使用率、内存与显存已用/总量、共享 GPU 内存、上传/下载和磁盘读写速率均可选。设备与采样间隔是共享设置：默认 1 秒，可调 1–60 秒；网卡与显卡支持自动或手选，磁盘支持全部或单盘。

- CPU 为全机处理器使用率；内存来自 Windows 的物理内存状态。
- 网速使用接口累计字节的时间差。自动模式统计活动物理网卡，避免把 VPN 与物理承载重复相加；手选可包含虚拟接口。
- GPU 固定所选适配器，显示型号；使用率取聚合后的最忙引擎，不能理解为所有引擎相加。显存使用量为全机适配器统计，容量来自适配器描述；核显或无法确定容量时不伪造百分比。
- 磁盘读写使用全部磁盘总计或某一个磁盘实例，二者不重复相加。

计数器、驱动或设备不可用时显示 `—`，有效零值才显示 `0`。速率首次采样、从休眠恢复、切换设备或累计计数回退时重新建立基线。每个显示根据自己的依赖判断是否过期。系统数据不需要额外驱动或管理员权限；不同硬件的 GPU/显存计数器可用性可能不同。

## 数据源与单位

内置 OKX、Binance、KuCoin 公开行情；Binance 使用只读行情域名。预置美股、ETF 和部分沪深股票使用 Yahoo Finance 公共图表端点。Yahoo 不是稳定性受保证的官方开放 API，数据可能延迟、限流或暂时不可用。

自动行情行显示报价货币（如 USDT、BTC、USD、CNY）。自定义字段可以设置任意单位。接口返回的文本保持原值；需要格式化数字字符串时，在显示行中明确选择小数格式。

单位显示可选完整代码、简写（如 USDT → U）或自定义标签；单改标签不改数值。价格换算支持 USD、CNY、EUR、GBP、HKD、JPY、USDT、USDC，使用 Coinbase USD 基准参考汇率，每 5 分钟刷新，USDT/USDC 不假设与美元等值。汇率缺失、失效或换算失败时保留原值和原单位。其他数值可设置“原单位 → 目标单位 × 固定倍率”；手工倍率优先，温度偏移等非线性转换不属于倍率转换。

加密行情默认约 15 秒刷新、Yahoo 约 60 秒刷新；自定义接口间隔为 15–3600 秒。每个来源独立刷新，失败时保留上次值并标记过期，悬停可查看更新时间和原因。

悬浮窗不显示底部常驻状态栏。把鼠标停在具体数据上，可查看更新时间和错误信息；获取失败保留上次数据，并显示过期提示。

网络自动跟随 Windows 系统网络设置；连接失败时保留上次数据，悬停可查看简短的错误原因。

自定义 API 只支持 HTTPS GET JSON，拒绝重定向和在 URL 中放置常见密钥参数；API Key 请使用受保护的请求头。

天气模板使用 [Open-Meteo](https://open-meteo.com/en/docs)，遵循其个人非商业服务限制和署名要求；仓库模板使用 [GitHub REST API](https://docs.github.com/en/rest/repos/repos#get-a-repository)。公开接口可能限流或临时不可用，网络模板不会在首次启动时自动添加。

## 常见问题：数据、升级与迁移

<a id="storage"></a>

### 配置存在哪？便携模式与系统目录有什么区别？

个人数据默认位于 `duomonitor.exe` 同级的 `user_data`，也可在设置中改到 `%APPDATA%\DuoMonitor`。当前数据目录内的 `settings.json` 保存配置，保存前保留 `.bak`，文件损坏时尝试恢复备份；交易对缓存、导入图标和受保护的密钥文件也跟随所选目录。移动或备份软件时，保留完整的当前数据目录。

切换前先保存当前草稿。“复制当前数据”会复制配置、图标、备份、缓存、密钥和日志，源目录保留；目标中的同名数据会先保留在 `migration-backups`。不复制时读取目标已有的设置，没有设置则使用默认配置；失败时继续使用原数据位置。程序旁的 `duomonitor_storage.json` 记录选择，兼容旧 `metricperch_storage.json`；程序目录不可写时使用系统目录下按程序路径区分的选择记录。已选用旧 `%APPDATA%\MetricPerch` 的数据会复制到新系统目录，旧目录保留。

<a id="diagnostics"></a>

### 诊断日志存在哪？

任务栏诊断也保存在当前数据目录的 `taskbar-bridge.log` 和 `taskbar-helper.log` 中。日志仅记录固定状态、错误代码和计数，不记录行情内容、API 地址或密钥；每个日志上限为 64 KiB，并保留一份轮换备份。

<a id="upgrade"></a>

### 怎样升级并保留旧设置？

先退出旧版、备份完整的当前数据目录，再解压新包。便携模式把 `user_data` 复制到新程序旁；系统模式在新程序的“导入与数据位置”中重新选择原系统数据目录，并选择 **不复制，只切换**，以读取已有配置。

原 CryptoFloat 便携配置自动升级为双显示配置，并保留迁移前原始备份。悬浮窗的关注项、模板、排序、字体、主题、自定义标题和图标保留；升级默认新增任务栏系统监测。MetricPerch 配置继续读取，已保存的标题不被改名覆盖。已保存的任务栏关闭选择在后续启动中保留。高于当前支持版本的配置不会被默认设置覆盖。改名沿用旧单实例与密钥引用标识；不要同时启动旧新版本。

程序会记住所选数据位置；未选择位置的既有便携版继续使用自己的 `user_data`。所选目录没有设置时从默认配置开始，不自动读取、复制或迁移旧 `%APPDATA%\CryptoFloatFlutter` 与 `%LOCALAPPDATA%\CryptoFloat\secrets`。

<a id="secrets"></a>

### API Key 安全吗？配置是否全部加密？

请求头密钥使用 Windows DPAPI 本地加密，配置保存密钥引用。普通 `settings.json`、缓存和日志并非整体加密文件，分享前请检查内容。DPAPI 密钥保护仍绑定当前用户和电脑，换电脑或账户后需要重新输入 API 密钥。

发行 ZIP 不含个人数据和数据位置标记。分享程序请使用原始发行 ZIP；备份个人配置时另行复制当前数据目录。

<a id="legacy-import"></a>

### 怎样导入早期设置？

在“关注行情”的“导入与数据位置”中选择导入旧版设置，填写旧 `crypto_config.json` 的位置。导入先形成草稿，点击保存或关闭设置时保存后应用；旧文件不被修改。兼容的行情选择、顺序、字体和显示行可以迁移，旧密钥需要重新输入。

## 窗口与显示器

窗口位置和大小保存在设置中。Windows runner 使用 PerMonitorV2 DPI；保存的显示器消失或窗口完全离屏时，恢复到主屏可见区域。

DPI 处理、跨屏复测和验证范围见 [DPI 调查记录](verification/dpi-investigation.md)。历史修正见 [更新日志](../CHANGELOG.md)。
