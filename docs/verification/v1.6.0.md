# DuoMonitor v1.6.0 verification

Date: 2026-10-15. Application version: `1.6.0+13`.

## Scope

This release adds a fixed settings preview, compact and configurable display
spacing, independent taskbar price/24h colors, adaptive taskbar width and paging,
and per-asset price precision with standard or K/M/B notation. The floating and
taskbar displays retain separate formatting preferences. Source values and price
direction calculations are not rounded.

## Automated verification

- Final Flutter static analysis: no issues.
- Final complete Flutter suite: 252 passed, 1 optional installed-font fixture
  skipped.
- Native taskbar suite: 147 checks passed; production helper compiled.
- Native monitor channel suite: 44 checks passed.
- Final Windows x64 release build and whitelist packaging succeeded after the
  last production edit.
- Independent source review and follow-up checks found no remaining release
  blocker. Final documentation/version review matched the implementation.

Regression coverage includes separate price-tick and 24h percentage colors,
per-display settings serialization, compact rounding across K/M/B boundaries,
decimal overrides, explicit custom-template formats, configurable gaps, preview
draft/save behavior, and the supported 320x360 settings size. Large taskbar text
in that compact preview is exercised with paging, mouse-wheel input and actual
scrollbar-thumb dragging.

Taskbar checks cover verified free-region selection without the previous width
cap, occupied regions, missing/stale observations, complete-column pagination,
rotation intervals, hover/manual pause, high-resolution wheel accumulation,
refreshes that do not restart the paging deadline, and segmented text/colors.
The display protocol preserves legacy fields while enforcing its 64 KiB limit;
tests exercise up to 256 cells and long Unicode content.

## Visual inspection

Settings widget renders were inspected at ordinary and minimum window sizes.
The actual native taskbar renderer was exercised offscreen with separate price
and percentage colors, a wide layout exceeding the old configured width, and
multiple narrow pages. These checks validate rendering in the supplied fixtures;
they are not live Explorer desktop acceptance tests.

## Limits

The native taskbar integration targets the primary horizontal Windows taskbar.
This round did not perform a live Explorer desktop or mixed-DPI acceptance test.
Unknown or stale taskbar geometry causes the helper to hide until verified free
space is available. macOS/Linux remain untested platform scaffolds.

An unsaved newly selected market without an existing quote displays a placeholder
in preview until data becomes available after saving. Preview does not issue
independent network requests. GitHub publication is verified separately against
the release record, tag commit and uploaded asset digest.
