## Read-only desktop diagnosis

The tested setup has three monitors at 175%, 100%, and 175%. The primary Windows taskbar uses PerMonitorV2 awareness. Both the original v1.3.0 discovery and the repaired discovery found adequate space within 62–109 ms. No application or helper process was running during this inspection.

The empty-rectangle fix addresses a documented discovery defect, but these read-only results do **not** establish that it caused the reported invisible taskbar. No interactive cross-monitor drag was performed.

## Authorized temporary application check

A temporary copy was launched with a copy of the existing portable configuration. The original configuration was retained. The helper reported `displaying`, and its child window was visible in the native window hierarchy, at the expected physical bounds and at the top of its siblings. A taskbar-only screen capture nevertheless showed no metrics, while rendering that owned child into an image produced the expected data. This isolates the failure to final on-screen composition, rather than discovery, data delivery, or text rendering.

Microsoft documents that [DirectComposition can have a visual layer above child windows](https://learn.microsoft.com/en-us/windows/win32/api/dcomp/nf-dcomp-idcompositiondevice-createtargetforhwnd). That behavior is consistent with the observed failure. The application's own child window now uses an opaque layered surface. With only that change, the same temporary application displayed its data in an actual taskbar screenshot. This A/B check confirms the fix on the tested Windows 11 desktop; it does not establish compatibility with every taskbar customization or future Windows version. The helper's reported state alone is not a screen-pixel assertion.

Both temporary application runs and their helper processes were closed after checking. No Explorer window styles, taskbar button positions, or other application windows were modified. Captures and copied user data remain local and are excluded from source and release archives.

The portable taskbar diagnostics record bounded phase/state, error-code, and numeric geometry/count information. They exclude quote text, API values, window titles, and credentials; public bundles exclude all runtime logs and `user_data`.
