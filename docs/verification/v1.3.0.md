# v1.3.0 verification

## Automated checks

- Flutter static analysis: no issues.
- Flutter tests: 139 passed, including migration, independent profiles, shared polling, custom field isolation, ordering, English/Chinese compact settings, cancellation and template freshness.
- Native taskbar checks: 42 passed, covering bounded protocol, layout, rendering, helper lifecycle and delayed discovery withdrawal/recovery.
- Native method-channel codec: 31 assertions passed.
- System sampler: deterministic calculations and isolated lifecycle checks passed; a read-only sample on the development machine returned valid values for all 13 metrics.
- Windows release build: main application and isolated taskbar helper compiled and packaged successfully.

## Review changes

Independent reviews identified and corrected stale discovery timestamps, physical mobile-broadband adapter selection, per-field custom API status, redundant refresh on appearance changes, mixed-order reconciliation, preview font/column mismatches, and field/unit reference deletion guards.

## Distribution checks

The Windows bundle is assembled from an explicit runtime allowlist. It excludes user configuration, credentials, diagnostic logs and debugging symbols. Source and bundle scans found no development-user identity or personal workspace path. The public README screenshot was provided and explicitly approved by the project owner.

## Limits

No production application or taskbar helper was launched on the user's desktop during this work. Real taskbar embedding, Explorer restart, auto-hide, hotplug, sleep/wake and mixed-monitor DPI behavior still need live compatibility testing. Isolated tests verify behavior under controlled inputs; they do not certify every Windows taskbar layout. macOS/Linux native adapters remain future work.
