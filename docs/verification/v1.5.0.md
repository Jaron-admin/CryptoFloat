# DuoMonitor v1.5.0 verification

Date: 2026-10-14.

## Scope

MetricPerch is renamed to DuoMonitor. This release adds portable/system data
selection, right-aligned floating numeric values, monospace font guidance, and
shared price-color modes based on the previous successful refresh.

## Automated verification

- Flutter static analysis: no issues.
- Complete Flutter suite: 230 passed, 1 optional installed-font fixture skipped.
  An existing narrow-layout test emits a non-fatal tap hit-test warning.
- Native taskbar suite: 124 checks passed; renamed helper compiled.
- Native monitor channel: 36 checks passed.
- Native window suite: 193 checks passed.
- Native DPI diagnostics: 63 checks passed.
- New native storage routing test passed with isolated application/profile roots.
- Windows x64 release build and whitelist packaging succeeded.
- Independent source review found one missing-font migration issue; both copy and
  no-copy regressions failed before the fix and passed afterward. Follow-up
  review found no remaining release blocker.

Storage tests cover retaining old portable settings, selecting existing target
settings without overwriting them, retaining destination collisions in backups,
rolling back ordinary copy/selector failures, a read-only application selector,
legacy system data/credential migration, and unavailable saved fonts. The source
directory is retained. Migration does not implement a power-failure journal.

Price tests cover first sample, rise/fall, unchanged price, unchanged provider
timestamps, failed requests and recovery, duplicate UI notifications, both
display targets, and independent 24-hour percentage coloring. Layout tests cover
numeric strings, both entry directions, and long custom unit labels.
